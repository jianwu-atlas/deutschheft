# 2_2026-04-20 第二次德文课程-数字

为了帮助你系统、高效地掌握德语数字，我将前面图片中的核心知识点进行了学术化的梳理，为你整理出一份结构清晰、易于查阅的**德语数字全攻略**。

## 一、 基础基数词（0–12）：不规则的基石

这13个数字是德语计数的底层核心，属于**不规则变化**，必须牢固记忆（后附中文近似发音）：

| **阿拉伯数字** | **德语单词** | **近似中文发音** | **记忆要点** |
| --- | --- | --- | --- |
| **0** | **null** | 怒（儿） | 结尾舌尖要轻微抵住上颚 |
| **1** | **eins** | 爱音词 | 组合成两位数时会发生变化 |
| **2** | **zwei** | 茨外 | **z** 永远发“茨”，**w** 发英文 "v" 的咬唇音 |
| **3** | **drei** | 德来 | 可练习小舌颤音 |
| **4** | **vier** | 飞儿 | **v** 在这里发 "f" 的音 |
| **5** | **fünf** | 芬夫 | 注意元音变音 **ü**（口型像吹哨） |
| **6** | **sechs** | 赛克斯 | 这里的 **s** 发浊音（英文 "z"） |
| **7** | **sieben** | 兹本 | 双音节单词 |
| **8** | **acht** | 阿赫特 | **ch** 是喉部摩擦音 |
| **9** | **neun** | 诺因 | 复元音 eu 发音类似“奥伊” |
| **10** | **zehn** | 曾 | 十位数的词尾来源 |
| **11** | **elf** | 艾尔夫 | 独立不规则 |
| **12** | **zwölf** | 茨沃尔夫 | 注意元音变音 **ö** |

## 二、 少年数字（13–19）：个位 + zehn

13 到 19 的构成逻辑非常纯粹：**“个位数 + zehn（10）”**。

> 🔊 **统一后缀发音：** `-zehn` 发音类似 **“曾”**。
> 
- **13** = **dreizehn** (*drei* + *zehn*)
- **14** = **vierzehn** (*vier* + *zehn*)
- **15** = **fünfzehn** (*fünf* + *zehn*)
- **18** = **achtzehn** (*acht* + *zehn*)
- **19** = **neunzehn** (*neun* + *zehn*)

### ⚠️ 核心纠错陷阱（词干脱落）：

- **16** = **sechzehn**：注意 *sech**s*** 结尾的 **s** 被省略了！
- **17** = **siebzehn**：注意 *sieb**en*** 结尾的 **en** 被省略了！

## 三、 整十位数（Zehner）：个位 + zig

整十位数的后缀通常是 **-zig**。

> 🔊 **统一后缀发音：** `-zig` 在标准德语中读作 **“茨希”**（带有轻微的摩擦音）。
> 
- **20** = **zwanzig**（特殊词干）
- **40** = **vierzig**
- **50** = **fünfzig**
- **80** = **achtzig**
- **90** = **neunzig**
- **100** = **hundert**

### ⚠️ 核心纠错陷阱：

1. **30** = **dreißig**：**大特例！** 它是整十位数中唯一使用 **ß** 而不是 *z* 的数字。
2. **60** = **sechzig**：同16一样，省略了 **s**。
3. **70** = **siebzig**：同17一样，省略了 **en**。

## 四、 21–99的组合数字：德语的核心颠倒逻辑

对于 21 及以上的两位数，德语采用了“先说个位，再说十位”的逆向逻辑。

$$\text{组合公式} = \text{个位数} + \text{und（和）} + \text{整十位数}$$

整个数字在书写时**必须连写成一个长单词，中间不留空格**。

### 💡 核心规则：1 的特殊变身

当个位数是 **1 (eins)** 时，一旦组合进两位数，必须**去掉末尾的 s**，变成 **ein-**。

- **21** = **ein**undzwanzig （*ein* + *und* + *zwanzig*）
- **31** = **ein**unddreißig （*ein* + *und* + *dreißig*）

### 经典实例拆解：

- **34** = **vier**und**dreißig** （4 + 和 + 30）
- **45** = **fünf**und**vierzig** （5 + 和 + 40）
- **56** = **sechs**und**fünfzig** （6 + 和 + 50）
- **67** = **sieben**und**sechzig** （7 + 和 + 60）
- **79** = **neun**und**siebzig** （9 + 和 + 70）

## 🛠️ 初学者实战纠错与应用指南

### 1. 听写与阅读时的“算法思维”

由于德语的阅读顺序（十位$\rightarrow$个位）与它的语言表达顺序（个位$\rightarrow$十位）相反，在实际应用中：

- **当你听到 `neunundsiebzig` (79)**：在大脑中先捕捉到第一个词 `neun` (9)，在纸上留出十位的位置，先写下 **9**，随后听到 `siebzig` (70)，再在左边补上 **7**。
- **防止镜像写反**：做选择或纠错时，看到 `dreiundzwanzig`（3+和+20）要立刻条件反射它是 **23**，而不是 *32*。

### 2. 生活场景应用（电话、门牌、邮编）

在用德语表达个人信息时（如 *Meine Telefonnummer ist...*）：

- **电话号码**：通常**逐位**念出数字（如 0176 念作 *null-eins-sieben-sechs...*），这是最安全、最清晰的沟通方式。
- **邮政编码（PLZ）**：德国的邮编是固定 5 位数。初学阶段同样建议逐字读出，例如 `35390` 读作 *drei - fünf - drei - neun - null*。

掌握了 0-100 的数字逻辑，后续进入成千上万的大数字学习时，规则也是完全一脉相承的。建议平时在路上看到车牌或门牌时，可以在脑中做一下高频的“逆向转换”练习！

### 1. 基础基数词 (0–12)

这部分是所有数字的基础，发音各异：

- **0 null**: 怒（儿）[nʊl] - *结尾有一个轻微的舌尖抵住上颚的发音。*
- **1 eins**: 爱音词 [aɪns] - *类似英文 "eyes" 加个 n 的音。*
- **2 zwei**: 茨外 [tsvaɪ] - *注意 "z" 发 "ts" 的音，不要发成“贼”。*
- **3 drei**: 德来 [draɪ] - *如果有能力，"r" 可以发一点小舌颤音。*
- **4 vier**: 飞儿 [fiːɐ] - *德语中 "v" 发 "f" 的音。*
- **5 fünf**: 芬夫 [fʏnf] - *注意 ü 的发音（口型像吹哨）。*
- **6 sechs**: 赛克斯 [zɛks] - *这里的 "s" 发浊音，像英文 "z"。*
- **7 sieben**: 兹本 [ˈziːbn̩]
- **8 acht**: 阿赫特 [axt] - *“赫”是嗓子眼里发出的摩擦音，类似吐痰前的准备动作。*
- **9 neun**: 诺因 [nɔʏn]
- **10 zehn**: 曾 [tseːn]
- **11 elf**: 艾尔夫 [ɛlf]
- **12 zwölf**: 茨沃尔夫 [tsvœlf] - *ö 的发音口型像“哦”，但发音靠近“诶”。*

---

### 2. 少年数字 (13–19)

后缀 **-zehn** 发音类似 **“曾”**：

- **13 dreizehn**: 德来-曾
- **16 sechzehn**: 赛赫-曾 - *注意：60和16中，6末尾的 s 都不发音。*
- **17 siebzehn**: 兹普-曾 - *70和17中，7末尾的 en 都省略了。*

---

### 3. 整十位数 (Zehner)

后缀 **-zig** 在标准德语中发音类似 **“茨希”**（[tsɪç]），但在南方地区也常读作 **“茨格”**。

- **20 zwanzig**: 茨万-茨希
- **30 dreißig**: 德来-希 - *注意：它是唯一的 -ßig 结尾。*
- **40 vierzig**: 飞儿-茨希
- **50 fünfzig**: 芬夫-茨希
- **60 sechzig**: 赛赫-茨希
- **70 siebzig**: 兹普-茨希
- **80 achtzig**: 阿赫特-茨希
- **90 neunzig**: 诺因-茨希
- **100 hundert**: 混德特 [ˈhʊndɐt]

---

### 4. 组合数字 (例如 21, 34...)

德语特色：**个位 + und (恩德) + 十位**

- **21 einundzwanzig**: 爱音-温德-茨万茨希
- **58 achtundfünfzig**: 阿赫特-温德-芬夫茨希

---

### 💡 核心发音避坑指南：

1. **Z 的陷阱**：德语的 **Z** 永远发 **“茨” (ts)**，千万不要读成“在”或英文的 "z"。
2. **V 的变声**：数字 4 (*vier*) 和 14 (*vierzehn*) 里的 **V** 都要发 **“F”** 的音。
3. **W 的转向**：数字 2 (*zwei*) 和 20 (*zwanzig*) 里的 **W** 要发类似英文 **"V"** 的咬唇音，不要发成“乌”。

### 这份学习资料详细介绍了德语中**数字（Zahlen）**的构成逻辑，特别是从 0 到 100 的计数规则。

以下是内容的结构化解读：

### 1. 基础数字：0–20 (Zahlen 0–20)

这是德语计数的基石，分为三个部分：

- **0–12：** 属于不规则变化，必须单独记忆（如 *null, eins, zwei... zwölf*）。
- **13–19：** 构成逻辑是 **“个位数 + zehn (10)”**。
    - 例如：13 是 *dreizehn* (3+10)，14 是 *vierzehn* (4+10)。
    - **注意拼写微调：** 16 (*sechzehn*) 省略了 s，17 (*siebzehn*) 省略了 en。
- **20：** *zwanzig*。

---

### 2. 整十位数 (Zehner)

整十位数的后缀通常是 **-zig**：

- 20: *zwanzig*
- 30: *dreißig* （注意：它是唯一使用 **ß** 而不是 z 的整十数）
- 40-90: 逻辑为 **“个位数 + zig”**（如 40 是 *vierzig*）。
- 100: *hundert*。

---

### 3. 21 及以上的组合规则 (Regel: Zahlen ab 21)

这是德语数字最特别的地方：**先说个位，再说十位**，中间用 **und** (和) 连接。

**公式：个位数 + und + 十位数**

- **21：** *einundzwanzig* (1 + 和 + 20)
    - *注意：* 当 1 (eins) 出现在组合数字中时，要去掉末尾的 **s**，变成 **ein**。
- **34：** *vierunddreißig* (4 + 和 + 30)
- **58：** *achtundfünfzig* (8 + 和 + 50)

### 二、 特别指出：常见误区与重点

根据笔记内容，有几个核心发音逻辑需要**重点标注**：

1. **V 与 W 的“移位”现象：**
    - **W** 读作 [ve:]（威），相当于英语的 V 音。
    - **V** 读作 [faʊ]（伐五），通常发英语的 F 音。这是初学者最容易混淆的地方。
2. **名词首字母大写 (Capitalization)：**
    - 图片顶部的三个问题：*Telefonnummer*, *Adresse*, *Hausnummer*。
    - 在德语中，这三个都是名词，首字母必须大写。笔记中在这些词下方划了红线，可能是在强调词首大写或重音位置。
3. **J 的独特性：**
    - 笔记中特意圈出了 **J** 对应 *yot*。在拼写名字时，千万不要把它读成英语的 "Jay"，否则德国人会听成字母 **G**。

### 三、 总结建议

这份笔记展示了典型的**对比学习法**。为了让发音更地道，建议在后续练习中注意以下两点：

- **长元音的饱满度：** 德语的 [e:]（如 P, G, W）比中文的“衣”更扁、更长，发音时嘴角要向两侧拉开。
- **清辅音的送气：** 德语的 P, T, K 在词首有非常明显的送气（类似小爆炸感），这比中文发音要强力得多。

这份材料非常实用，它直接关联了**个人信息查询**（电话、地址、门牌号）的实战场景。在口头回答这些问题时，准确拼读（buchstabieren）自己的名字是第一步。

### 一、 核心词汇解读

图片下方的三个德语词汇构成了“拼读”这一主题的逻辑链：

- **buchstabieren** (动词)：意为“拼读”。在德语中，当遇到不熟悉的姓名或单词时，常用此动词要求对方逐个字母报出。
- **der Buchstabe** (名词)：意为“字母”。注意其词性为阳性（der），复数形式为 *die Buchstaben*。
- **das Alphabet** (名词)：意为“字母表”。词性为中性（das），源自希腊语 *alphabētos*。

### 二、 重点关注：特别之处与德语特征

虽然图中展示的是标准的 A-Z 字母，但在德语语境下，有几个关键点需要特别指出：

### 1. 缺失的特殊字母 (Umlaute & Eszett)

图片中仅列出了基础的 26 个拉丁字母。然而，一个完整的德语字母表通常包含 **30个** 字母。图中缺失了以下极其重要的部分：

- **变元音 (Umlaute):** Ä ä, Ö ö, Ü ü。
- **变体字母:** ß (Eszett / scharfes S)，仅有小写形式（但在现代正字法中也引入了大写 ẞ）。

### 2. 书写习惯观察

- **字母 "J":** 图片中的 "J" 带有一个明显的顶部横钩或圆圈装饰。在德语手写体中，为了区分 "I" 和 "J"，"J" 往往写得更具辨识度。
- **字母 "W":** 在德语发音中，"W" 的发音对应英语中的 /v/（如 *Volkswagen* 读作 *Folks-vagen*），而 "V" 的发音则通常对应英语中的 /f/。

### 3. 词首大写规律

观察底部的名词（**B**uchstabe, **A**lphabet），它们的首字母均为大写。这是德语语法的一个核心特征：**所有名词（Noun）无论出现在句中任何位置，首字母必须大写。** 而动词（**b**uchstabieren）在非句首位置则保持小写。

### 三、 总结

这张图反映了典型的语言教学初期场景。其特别之处在于，它通过 **“动作 (Verb) -> 个体 (Singular Noun) -> 整体 (Collective Noun)”** 的结构建立了学习框架。

对于学习者而言，下一步的重点应是掌握这 26 个字母在德语中的**音名**（例如：A 读作 /a:/，W 读作 /ve:/），并补充学习上述缺失的 **Ä, Ö, Ü, ß**。

### 一、 核心发音体系总结

德语字母表的发音逻辑可以归纳为以下几个主要类别：

- **单元音系列 ([a:], [e:], [i:], [o:], [u:])**：
    - **A, E, I, O, U**：发音非常纯净，口型固定，不带滑动。特别注意 **E** 发“诶” ([e:])，而 **I** 发“依” ([i:])。
- **“-e” 结尾的辅音系列 ([be:], [tse:], [de:], [ge:], [pe:], [te:])**：
    - 这些字母（**B, C, D, G, P, T**）的音名都以长元音 [e:] 结尾。
    - **纠偏重点**：注意图中 **G** 标为“给” ([ge:])，**P** 标为“配” ([pe:])。这比英语式的 "gi" 或 "pi" 准确得多。
- **“-ε-” 夹心系列 ([ɛf], [ɛl], [ɛm], [ɛn], [ɛs], [ɛʁ])**：
    - 这些字母（**F, L, M, N, S, R**）发音时先发一个短促的 [ɛ]（类似“艾”）。
    - **R** 的音名 [ɛʁ] 包含了德语标志性的小舌音或喉音。

- **1. Vorstellung:** 自我介绍、姓名、国籍、职业。

### 2. 日常生活实务 (Daily Life & Logistics)

- **4. Bestellen (Café, Restaurant):** 餐饮订购，掌握点餐礼仪和词汇。
