## 二、三个方案对比

| | **A. 维持现状**（PDF 只读） | **B. 全量结构化** | **C. 教材精读模块**（推荐） |
|---|---|---|---|
| 做法 | 只在 PDF 里看 | 把 338 页全部拆成数据 | 按场景精选句型，三行格式呈现 |
| 可检索 | ❌ | ✅ | ✅ |
| 逐句朗读 | ❌ | ✅ | ✅ |
| 隐藏中文自测 | ❌ | ✅ | ✅ |
| 手机体验 | 差 | 好 | 好 |
| 工作量 | 0 | 很大（338 页） | **可控（分 3 期）** |
| 与现有版式复用 | — | 需新建 | **直接复用 `texte.html` 骨架** |

**为什么推荐 C**：你已有的 `texte.html` 三行版式（德文 / 音标 / 中文）已经解决了「排版 + 自测 + 朗读」三件事；教材只需要**把第三行从 IPA 换成中文谐音**（或并存），就能以最小改动接入。方案 B 的收益与 C 相同但成本高一个数量级。

### 3.2 数据 schema（新文件 `assets/js/data/sucheng.js`）

```js
/* 由 scripts/build_sucheng.py 从 OCR 全文 + 蒸馏知识库生成（勿手改） */
const SUCHENG = {
  meta: { id: "sucheng", zh: "零基础德语速成", extra: true },   // extra:true → 不计入生词表
  parts: [
    { id: "pron",  zh: "发音篇", lessons: [ /* … */ ] },
    { id: "scene", zh: "场景篇", scenes: [
      {
        id: "e6s6", einheit: 6, zh: "买家电家具",
        words: [ { de: "der Kühlschrank", zh: "冰箱", pron: "库尔施兰克" } ],
        sentences: [
          {
            de:   "OK, nehmen Sie es!",
            zh:   "好的，我买了。",
            pron: "Ok 内们贼艾斯",          // ← 三行格式的第三行（原书汉语谐音）
            ipa:  "[oˈkeː ˈneːmən ziː ʔɛs]"  // 可选：IPA 作为第四行/悬浮
          }
        ],
        tips: [ "nehmen 在此是「买」的意思" ]
      }
    ]},
    { id: "gram",  zh: "语法篇", topics: [ /* … */ ] }
  ]
};
```

**字段说明**：`de` 德语原文 / `zh` 中文翻译 / `pron` 中文近似发音 / `ipa` 可选（有则并列显示，无则只显示三行）。

## 四、三行格式的排版方案（重点）

### 4.1 视觉规范

```
┌─────────────────────────────────────────────────────────┐
│ OK, nehmen Sie es!                          🔊    ⧉     │  ← 第 1 行 德文原文
│                                                         │     16px / 500 / var(--ink)
│ 好的，我买了。                                            │  ← 第 2 行 中文翻译
│                                                         │     13.5px / var(--ink-2)
│ [ Ok 内们 贼 艾斯 ]                                       │  ← 第 3 行 中文谐音
└─────────────────────────────────────────────────────────┘     12.5px / var(--accent) 胶囊块
```

**为什么第三行用「胶囊块」**：与中文翻译在视觉上明确分层，避免读者把谐音当释义；同时与 `texte.html` 里 `s-ipa` 的胶囊风格一致，全站统一。

### 4.2 HTML 结构

```html
<div class="sc-sent">
  <p class="s-de">OK, nehmen Sie es!
    <button class="s-speak" title="朗读这句德语">🔊</button>
  </p>
  <p class="s-zh">好的，我买了。</p>
  <p class="s-pron">Ok 内们 贼 艾斯</p>
</div>
```

### 4.3 CSS（追加到 `assets/css/deutsch.css`）

```css

.sc-sent { padding: 14px 0; border-bottom: 1px solid var(--line, rgba(0,0,0,.07)); }
.sc-sent:last-child { border-bottom: 0; }

.sc-sent .s-de {
  margin: 0 0 6px; font-size: 16px; font-weight: 500; line-height: 1.6;

}
.sc-sent .s-zh {
```

### 4.4 真实样例（取自教材第 193 页「买家电家具」场景）

| 德文原文 | 中文翻译 | 中文近似发音 |
|---|---|---|
| OK, nehmen Sie es! | 好的，我买了。 | Ok 内们贼艾斯 |
| Wenn Sie es billiger machen, überlege ich es mir noch einmal. | 如果您能便宜一点我还会再来的。 | 问贼艾斯比例个吗很鱼博累个一西艾斯密额闹和 爱恩骂了 |
| Tut mir Leid, das ist mein letztes Angebot. | 真不好意思，这是我最后一次说价格了。 | 图特密额 来特大斯伊斯特买恩累词斯 安个博特 |
| Ich kann um ein paar Euro runter gehen, aber nicht so viel. | 我可以给您再降几欧元，但是多了就不可以了。 | 一西看鸟么爱恩怕凹爱欧 混特 给恩啊博 你西特揍飞偶 |

> 谐音行**逐字来自原书**（OCR 全文已保留），不是二次创作——这保证了「照书学」的一致性。

### 4.5 可选增强（建议但非必需）

1. **第四行 IPA**：`pron` 之后并列一行 IPA（有数据时显示），与 `texte.html` 统一。
2. **长句自动断句**：>20 词的句子按逗号切分，每段一行，谐音跟着切。
3. **一键生成 MP3**：复用 `tts.html` 的 `TTS_ENDPOINT`，整段德文 → 真 MP3。
4. **与生词表联动**：教材词**只**支持「查看释义 / 听发音」，**不**提供「加入生词表」。

## 六、风险与注意事项

| 风险 | 说明 | 对策 |
|---|---|---|
| **OCR 噪声** | 谐音行相对干净；德文行有 `uberlege→überlege`、`Kise→Käse` 类错误 | 生成脚本内置常见替换表；页内标注「OCR 校对中」 |
| **谐音非标准发音** | 中文谐音只是**辅助**，不能替代 IPA | 三行并存时把 IPA 放在最下，谐音居中；页内加提示 |
| **版权** | 教材为购买所得，站点为个人自用 | 保持私有用途；公开部署时 PDF 与精读正文建议仅自己可见（或加口令） |
| **课外词混入词表** | 新模块若直接 `VOCAB.push` 会污染词表 | 构建断言（§3.4）+ code review |
| **工作量大** | 338 页全量结构化不现实 | 采用方案 C 的**分阶段精选**策略 |
